# comp_vision

Практические работы по курсу «Компьютерное зрение».

## Структура репозитория

| Каталог | Тема | Содержимое |
|---------|------|------------|
| `lab1/` | Практическая работа № 1 «OpenCV» | Базовые операции с изображениями в OpenCV |
| `lab2/` | Практическая работа № 2 «Геометрические трансформации и специальные функции в библиотеке OpenCV» | Геометрические преобразования изображений |
| `lab3/` | Практическая работа № 3 «Pillow Library (PIL)» | Работа с изображениями средствами Pillow |

В каждом каталоге находятся:

- `task.txt` — текст задания;
- `Практическая работа N.ipynb` — Jupyter-ноутбук с выполненной работой;
- изображения, использованные в работе.

## Требования

- Python 3;
- библиотеки: `opencv-python`, `pillow`, `numpy`, `matplotlib`, `ipykernel`.

## Запуск

```bash
# создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate

# установка зависимостей
pip install opencv-python pillow numpy matplotlib ipykernel

# запуск Jupyter
jupyter notebook
```

После запуска Jupyter откройте ноутбук нужной практической работы из соответствующего каталога.
